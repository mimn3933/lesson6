---

## 📖 プロジェクトについて

HTML と CSS だけで作成した、シンプルな自己紹介ページです。
白いカードに名前・趣味・スキルをまとめ、アニメーションで動きのある見た目に仕上げています。

### ✨ 主な特徴

| 機能 | 説明 |
| --- | --- |
| 🎨 グラデーション背景 | 濃い青 → 水色の斜めグラデーション |
| 🃏 カードデザイン | 角丸・影付きの白いカードを画面中央に配置 |
| 🌊 フェードイン | ページを開くとカードが下からふわっと現れる |
| 🖱️ ホバー効果 | 趣味リストにマウスを乗せると背景色が変化 |
| 📊 スキルバー | 習熟度を示すバーが 0% から伸びるアニメーション |

---

## 🛠️ 使用技術

- **HTML** — ページの構造（見出し・段落・リスト・リンクなど）
- **CSS** — 見た目の装飾（Flexbox、グラデーション、`@keyframes` アニメーション、CSS 変数）
- **Google Fonts** — [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)
